# BasicStockroom
Resumo/Abstract
-   O projeto e baseado em um almoxarifado de forma virtual, em que é possível identificar ruas
 prateleiras, níveis e compartimento, a fim de facilitar a localização dos itens ali dispostos.
Abstract
-  The project is based on a virtual stockroom system that allows for the identification of aisles, shelves, levels, and compartments, thereby facilitating the location of the items stored there.
- Lista de funcionalidades
    -  Localização dos itens.
    -  Verificação de quantidade.
    -  Informar itens necessário para compra.
    -  Solicitar item para compra.
    -  Cadastrar item, Adicionar item no estoque, Remove item, Excluir item.
- List of features
    -  Item location.
    -  Quantity check.
    -  Report items needed for purchase.
    -  Request item for purchase.
    -  Register item, log item into stock, remove item from stock, delete item.
